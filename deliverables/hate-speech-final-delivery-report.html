01The system at a glance

Comment + context→ Shared BERT encoder→ Context interaction→ Contrastive representation→ hate / target / reason / evidence heads→ Integrated-Gradients evidence + char offsets→ Deterministic reason explainer→ Structured JSON→ Reasoning UI

The UI presents the reasoning chain as WHAT (prediction) → WHO (target) → WHY (reason) → WHICH PARTS (numbered, clickable evidence with attribution scores) → DID CONTEXT MATTER (context flag).

Honesty contract: no generative LLM anywhere — the explanation layer is deterministic template composition grounded in the predicted reason, target, and extracted evidence; evidence is attribution-based (not causal proof); every section renders only from real model outputs and unavailable sections are hidden with an explanation, never faked.

uvicorn app.main:app --port 8001

cd frontend
npm install
npm run dev        # http://localhost:5173
